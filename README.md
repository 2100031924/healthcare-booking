# Appointment Booking Page

AI Healthcare & Telemedicine Ecosystem - Appointment Booking Module

## Features
- Doctor listing with specialization filter
- Date and time slot selection
- Confirmation popup with booking summary
- Responsive UI (Mobile + Desktop)

## Tech Stack
- React.js
- Tailwind CSS
- React Router
- Vite
- Dummy JSON Data
